# EGM 검토 1회차 (2026-11-23)

- 대상: spec.md, design.md 초안
- 검토자: egm-implementation-readiness(코드 대조 포함), egm-comprehension(처음 보는 사람 관점, 문구). 부모 대화 없이 문서와 코드 경로만 전달

## 구현 준비도

| # | 지적 | 심각도 | 조치 |
|---|---|---|---|
| 1 | 저장소 API가 정의되지 않음 | 차단 | design 2절에 `createGuideStore` 함수 목록과 동작을 적음 |
| 2 | 이미 `/`에 있을 때 다시 열기와 포커스가 동작하지 않음 | 차단 | `focusRequested`를 구독 스냅샷에 넣고 컴포넌트 효과에서 포커스 후 해제 |
| 3 | FG-03 "각 단계에 링크"와 1단계 링크 없음이 모순 | 주요 | FG-03 문구 수정 |
| 4 | 완료 기록 위치가 모호, `AppHeader`에 역할 없음 | 주요 | design 3절에 효과 코드와 하이드레이션 순서 기록 |
| 5 | node 환경 vitest에서 저장소를 시험할 방법 없음 | 주요 | 저장소를 주입받는 `createGuideStore`로 바꿈 |
| 6 | 하이드레이션 경고는 수동 확인뿐 | 주요 | design 6절에 Playwright 확인 절차 추가 |
| 7 | 경로 판정 정규식 미정 | 사소 | 정규식을 적고 끝 슬래시와 하위 경로를 테스트 |
| 8 | 가운데 클릭은 역할이 안 바뀜 | 사소 | spec 오류 상황에 기록 |
| 9 | 닫은 뒤 포커스 규칙이 앞뒤가 다름 | 사소 | `main`으로 옮긴다로 통일 |
| 10 | 탭 간 동기화와 레이아웃 밀림 | 사소 | 범위 밖으로 명시, 밀림은 받아들임 |
| 11 | 모두 완료 표시가 FG-04와 다름 | 사소 | "3/3 완료 · 다 둘러봤어요"로 통일 |
| 12 | 설계 검토 전 `guide.test.ts`가 이미 있음 | 사소 | 검토를 기다리며 순수 함수만 먼저 썼다. 단계 ID 변경(inbox → approve)에 맞춰 고침 |
