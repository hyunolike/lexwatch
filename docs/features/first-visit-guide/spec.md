## 해결할 문제

공개 데모에 처음 들어온 사람(채용 담당자, 면접관, 법무 실무자)은 승인 대기함 목록부터 본다. 다음 세 가지를 알 길이 없다.

1. 이 제품이 무엇을 하는지. "공포된 법령 개정을 모아 AI가 실무그룹별 영향 검토 초안을 쓰고, 변호사가 근거를 대조해 승인해야 안내문이 나간다"는 흐름이 화면 어디에도 한 번에 적혀 있지 않다.
2. 어디부터 봐야 하는지. 핵심 장면(자동 검사인 크리틱이 근거와 맞지 않는 문장을 잡는 장면, 승인 직전에 자동 검사를 다시 돌리는 장면, 알림 발송, 실행 타임라인)이 세 화면과 두 역할에 흩어져 있다. 관리자 화면은 머리의 역할 전환을 눌러야 보인다.
3. AI가 틀릴 수 있다는 것. 초안은 자동 검사를 거치지만 모든 오류를 잡지 못하고, 그래서 변호사 승인이 필요하다는 설계 의도가 드러나지 않는다.

서버가 잠들어 있으면 첫 화면이 1분 가까이 "깨우는 중"이라 처음 방문자가 그 사이에 떠나기 쉽다.

## 범위

포함:
- 승인 대기함 위의 처음 방문 안내 영역과 둘러보기 세 단계
- 단계 완료 표시와 닫기, 다시 열기
- 브라우저 저장소에 안내 상태 저장

하지 않을 것:
- 화면 위에 겹치는 강조 투어(coach mark)와 여러 장짜리 대화상자. 근거는 research.md 1절
- 서버 저장. 로그인이 없는 데모라 방문자별 상태는 브라우저에만 둔다
- 각 화면의 문구 개편. 이미 있는 빈 상태와 안내 문구는 그대로 둔다

## 요구사항

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| FG-01 | 처음 방문하면 승인 대기함 위에 안내가 보인다 | 저장된 상태가 없는 브라우저에서 `/`를 열면 안내 영역이 목록보다 위에 있다. 서버를 깨우는 중에도 보인다 |
| FG-02 | 안내는 제품과 그 한계를 짧게 말한다 | 한 문단으로 흐름(수집, AI 초안, 자동 검사, 변호사 승인, 알림)을 말하고, "AI 초안은 틀릴 수 있고 자동 검사가 모든 오류를 잡지는 못한다"는 문장, 지금 보고 있는 역할, 데이터 초기화와 서버 깨우기 안내를 담는다. 사내 용어(실무그룹, 크리틱, 재현)는 풀어 쓰거나 괄호로 덧붙인다 |
| FG-03 | 둘러보기 세 단계를 링크로 준다 | (1) 확인 필요 초안 열기 (2) 승인하고 알림함 보기 (3) 관리자로 바꿔 실행 기록 보기. 1단계는 바로 아래 목록을 가리키고, 2단계는 알림함, 3단계는 실행 이력 링크가 있다. 3단계 링크는 역할을 관리자로 바꾼 뒤 실행 이력 목록(`/runs`)으로 이동한다 |
| FG-04 | 해당 동작을 하면 단계가 완료로 표시된다 | (1) `/reviews/<id>`를 열었다 (2) 승인이 성공했다(알림함만 열어서는 완료가 아니다) (3) 관리자 역할로 `/runs/<id>`를 열었다. 완료는 아이콘과 글자로 표시하고 색만 쓰지 않는다. 완료 수가 "n/3 완료"로 보이고, 모두 마치면 "3/3 완료" 옆에 "다 둘러봤어요"를 덧붙인다 |
| FG-05 | 닫을 수 있고 다시 열 수 있다 | 닫기를 누르면 사라지고 새로고침해도 나오지 않는다. 머리의 "둘러보기" 버튼을 누르면 `/`에서 다시 보이고 포커스가 안내 제목으로 간다. 완료 기록은 닫아도 남는다 |
| FG-06 | 저장소가 막혀도 깨지지 않는다 | 저장소 읽기나 쓰기가 예외를 내면 처음 방문처럼 안내를 보이고, 닫기는 그 화면에서만 유지된다. 오류가 화면에 나오지 않는다 |
| FG-07 | 접근성 | 안내는 제목이 있는 `section`이고 대화상자가 아니다. 단계는 순서 목록이다. 닫기 버튼에 이름이 있다. 서버 렌더링과 첫 클라이언트 렌더링이 달라 생기는 하이드레이션 경고가 없다 |

## 오류 상황

- 저장된 값이 깨진 JSON이거나 모르는 형식이면 버리고 처음 상태로 본다.
- 실행이 하나도 없으면 3단계는 완료할 수 없다. 실행 이력 목록의 빈 상태 문구가 이어서 안내한다. 매일 새벽 초기화 때 예시 실행(재현 예시)이 함께 만들어지므로 공개 데모에서는 생기지 않는다.
- 3단계 링크를 가운데 클릭이나 Ctrl 클릭으로 새 탭에 열면 역할이 바뀌지 않는다. 새 탭은 변호사 역할로 실행 이력을 보여 주고, 3단계는 머리에서 관리자로 바꿔 실행을 열어야 완료된다.
- 여러 탭에서 안내 상태를 맞추지 않는다. 다른 탭의 변경은 새로고침하면 반영된다.
