# 명세: 데모 신뢰도 1순위 (2026-11-19)

- 작성: hh.jang
- 관련: [README](../../../README.md), [배포 런북](../../deploy.md)

## 해결할 문제

1. 공개 데모의 AI 서비스에 NVIDIA 키가 없어 분류가 대체 구현으로 돌았다. 실수집 3건이 모두 "관련 없음"으로 닫혀, 데모를 열면 재현 예시만 보인다.
2. 크리틱 평가 케이스가 예시 조문이라 "맞춰 쓴 결과"라는 한계가 컸다. 법령 ID 하나(`001791`)는 실제로 결핵예방법이었다.
3. Vercel(web, ai)이 테스트 결과를 기다리지 않고 배포됐다.

## 요구사항

| ID | 요구사항 | 수용 기준 | 상태 |
|---|---|---|---|
| DR-01 | 평가 케이스의 근거를 실제 법령 녹화본으로 | 모든 근거 본문을 운영 파서로 녹화본에서 뽑는다. 판례는 대법원 실판례 | 완료 |
| DR-02 | 평가가 여러 문장 초안을 다룬다 | 과잉해석이 둘째 이후 문장에 있는 케이스 3건 이상 | 완료 |
| DR-03 | 패턴 규칙의 한계를 숨기지 않는다 | 실제 데이터에서 놓치는 케이스를 테스트에 알려진 누락으로 명시하고 README에 적는다 | 완료 |
| DR-04 | Vercel도 테스트 통과 뒤에만 프로덕션 배포 | `deploy-vercel` 잡, Git 연동의 `main` 프로덕션 배포 끔. PR 미리보기는 유지 | 구현 완료, `VERCEL_TOKEN` 필요 |
| DR-05 | 공개 데모가 NVIDIA 모델로 동작 | Vercel ai `NVIDIA_API_KEY` 설정 뒤 재배포, 새 수집에서 출처 라벨이 NVIDIA | 키 필요 |
| DR-06 | 같은 케이스로 NVIDIA 실호출 평가 | 규칙 있음, 없음 두 모드 결과를 `eval/results/`에 저장하고 README 표 갱신 | 키 필요 |

## 결정

- **케이스 구성**: 과잉해석 13(규칙마다 2건 이상, 여러 문장 3건), 정상 7. 근거는 근로기준법 제50조와 제56조, 개인정보 보호법 제29조와 제34조, 전자금융거래법 제9조와 제21조, 동물보호법 제101조 신구조문, 대법원 2020도16228, 2022두68923.
- **OC-05**: 최근 30일 개정 100건에서 과태료 금액이 바뀐 신구조문은 동물보호법 하나였다. 과태료 단계가 한 칸씩 올라 개정 전 금액이 개정 후 다른 항에 남는다. 패턴 규칙을 이번에 고치지 않고, 놓치는 사실을 기록한다(규칙 보강은 다음 작업).
- **Vercel 배포 방식**: 저장소 루트에서 `vercel deploy --prod`. 프로젝트 Root Directory 설정을 따른다는 것을 미리보기 배포 두 건으로 확인했다. 팀 ID와 프로젝트 ID는 비밀이 아니라 워크플로에 적고, 토큰만 시크릿으로 둔다.
- **키 입력**: NVIDIA 키와 Vercel 토큰은 작성자가 직접 넣는다.

- AI 테스트 77건 통과(패턴 판정이 알려진 누락 2건 외 모든 케이스를 올바른 문장 위치에서 적발, 정상 케이스 적발 0)
