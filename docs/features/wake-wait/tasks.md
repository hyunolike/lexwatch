# 작업: 서버 깨우는 동안의 대기 화면

- 명세: [spec.md](spec.md), 설계: [design.md](design.md), 검토: [reviews/2026-11-24-round1.md](reviews/2026-11-24-round1.md)
- 진행: 작업 1~6 완료(2026-11-24)
- 검증(2026-11-24):
  - 웹 vitest 145건 통과(새 17건), `tsc --noEmit`, `eslint src`, `pnpm build` 통과
  - 로컬 화면(API 컨테이너를 멈췄다 켜며, Playwright 1280×800):
    - 서버가 깨어 있을 때 대기 화면이 뜨지 않고 바로 목록이 보임
    - API를 멈추고 처음 방문하면 대기 화면이 뜸. 처음 방문 안내가 열린 상태에서 대기 화면 제목이 552px, 시간 막대가 645px에 있어 첫 화면 안에 보임(WW-05)
    - 경과 시간이 "6초째"에서 "1분 1초째"로 오르고, 60초가 지나면 안내 문장이 "평소보다 오래 걸리고 있어요…"로 바뀌며 막대가 줄무늬로 바뀜
    - 렉스를 두 번 누르면 잠꼬대가 바뀌고 "렉스를 2번 흔들었어요"가 보임. 다음 이야기와 멈춤(`aria-pressed=true`) 동작
    - API를 다시 켜면 "서버 깨우기 (완료)"와 "준비됐어요"가 보인 뒤 5.2초 만에 목록이 뜸
    - 폭 375px 가로 스크롤 없음, 움직임 줄이기 에뮬레이션에서 숨쉬기 애니메이션 길이 0초, 콘솔 오류 0건(API를 멈춰 생긴 네트워크 오류는 제외)
  - 운영(Render)처럼 요청이 붙잡히는 상황은 로컬에서 재현하지 않았다. 로컬은 연결 거부라 5초마다 다시 시도한다
