# LexWatch 소개 영상 계획

- 대상: README를 먼저 여는 채용 담당자(법무법인 IT). 소리 없이 봐도 이해되어야 한다.
- 톤: polished. 차분한 남색 바탕, 긴 정지, 부드러운 페이드. 음악은 낮은 패드 하나.
- 형식: 1920×1080, 30fps, 약 32초. 스킬 권장(20초)보다 길지만 실제 화면 세 장면과 한국어 자막을 읽을 시간이 필요하다.
- 소재: 로컬 `docker compose` 스택의 실제 화면을 Playwright로 캡처하고, 커서와 확대, 강조 상자를 합성한다. 재현 예시(04-critic-tier2, 근로기준법 제56조)를 쓴다.
- 정체성: 브랜드 남색 #1f2a44, 바탕 #f6f7f9, Pretendard, 마스코트 Lex.

## 한 줄
AI가 쓴 법령 검토 초안을, 근거와 대조해 걸러 내고 변호사가 승인해야 팀에 보낸다.
